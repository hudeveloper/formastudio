# forma studio — Bespoke Armchair Digital Atelier

A luxury 3D interactive showcase and bespoke procurement experience for designer armchairs, blending high-end architectural aesthetics with WebGL / Three.js 3D rendering and smooth micro-interactions.

---

## ✨ Highlights & Features

- **Interactive 3D Armchair Stage**: Real-time Three.js WebGL rendering with smooth camera orbit controls, shadow casting, and cinematic environment lighting.
- **Dynamic Colorway Curation**: Instant switching between designer editions (Sapphire, Emerald, Terracotta, Ivory, Obsidian, Citrine, Burgundy, Heather) with synchronous 3D material updates and dynamic ambient navbar theming.
- **Full-Page Bespoke Cart & Checkout**:
  - Colorway switcher with live pricing recalculation.
  - Interactive white-glove delivery options and VIP atelier production tracker.
  - Promo code discounts (`FORMA10`).
  - Celebratory luxury confetti and animated SVG checkmark confirmation modal.
- **Sticky Luxury Navigation**: Sticky glassmorphism header matching the active variant backdrop color on scroll, with quick-access shopping bag counter and spotlight search.
- **Spotlight Search & Direct Concierge Modals**: Smooth scale-and-fade modals for real-time catalog search and direct concierge consultations.
- **About Us & Craftsmanship**: Detailed atelier philosophy, master craft cards, and studio metrics.
- **Design Collective**: Interactive profiles of master architects and lead designers.
- **Bespoke FAQs Accordion**: Expandable answers addressing custom commissions, worldwide crating, and white-glove care.

## 🚀 Getting Started

### Prerequisites
A modern web browser with WebGL support (Google Chrome, Microsoft Edge, Firefox, Safari).

### Running Locally
To run the project with proper asset loading and local server setup:

1. Double-click `start-server.bat` (Windows), or
2. Run a simple local HTTP server using PowerShell:
   ```powershell
   python -m http.server 3000
   ```
   or with npx:
   ```bash
   npx serve .
   ```
3. Open `http://localhost:3000` in your browser.
